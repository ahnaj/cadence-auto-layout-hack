# Release readiness

**Development preview; not production-ready.**

Complete:
- Separate project, MIT license for authored code, no published remote.
- Native schematic input and configurable NCSU MOS mapping.
- Generic flat placement/routing, mirrored diffusion sharing, physical pins and labels.
- Isolated native OA library creation and editable-open audits.
- Real Diva DRC, extraction and LVS with retained private logs.
- Multiple native circuit/parameter/name tests, CLI, installer, documentation and public CI.

Remaining:
- More compact and reliable routing across congested general topologies; only one larger XOR candidate is fully verified.
- Hierarchical physical synthesis, including FA and multi-bit designs.
- Folding, vector terminals, additional primitives and body domains.
- Parent-level pin accessibility, row-abutment DRC, and broad PDK/version regression.
- Capacitance-aware extraction and post-layout simulation.
- GUI acceptance and redistributable screenshots.
- Broader area search and automatic repair beyond order/height trials and same-net gap repair.

Do not describe this release as universal, production-ready, or globally area-optimal. Use only a candidate whose own native DRC/LVS evidence passes.
