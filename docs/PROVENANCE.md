# Provenance and redistribution

The public tree contains newly authored implementation, original connectivity-only logic fixtures, documentation, unit tests and rendered layout images of those original fixtures. No proprietary PCell source, rule decks, technology libraries, OA binaries, course schematics, or private verification logs are included.

MIT applies only to this project's authored code and documentation. Cadence and NCSU/TSMC components remain under their respective licenses. Users supply them locally. Do not add private .local data or generated databases/logs to a release. The reviewed PNG examples contain only rendered fixture geometry and labels; see [image provenance](images/README.md).

Before publishing, inspect the exact Git index and run the public tests. Native measurements and verification logs remain local. No remote is created or pushed by project commands.
